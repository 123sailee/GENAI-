# WeekendYatri - Evaluation Questions

These questions will help evaluate whether WeekendYatri can answer users' travel-related queries using its current destination dataset.

1. Which destinations are available in Nashik district?

2. Which destinations are classified under the adventure category?

3. Which district has the highest number of destinations?

4. Suggest some nature destinations in Ahilyanagar.

5. Which destinations are suitable for visiting during winter?

6. What is the current bus fare from Nashik to Bhandardara?

   **Unanswerable with the current dataset:** The dataset does not contain current bus fares or ticket prices.

7. How can I reach Pandavleni Caves?

8. Which heritage destinations are available in Chhatrapati Sambhajinagar?

9. Suggest destinations suitable for the monsoon season.

10. How many destinations are available in each district?
